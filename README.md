# WhatsApp Web AI Assistant

Chrome extension v1.8.0 for language-aware, emotion-matched AI replies on WhatsApp Web. It uses the Gemini API and stores the API key in the extension's local storage.

## Install locally in Chrome

1. Download or clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the folder that contains `manifest.json`.
5. Open WhatsApp Web, open the extension side panel, and enter your own Gemini API key.

See [INSTALL.txt](INSTALL.txt) for the full usage instructions.

## Important

Automated replies may violate WhatsApp's terms and may put your account at risk. Use this extension only where you have permission and accept responsibility for automated messages. Never commit your API key to this repository.
